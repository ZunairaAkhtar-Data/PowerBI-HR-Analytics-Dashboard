# HR Analytics Dashboard (Power BI)

## Subject
Practice project to analyze employee performance, compensation, engagement, and retention using Power BI.

## Problem Statement
Organizations often have large HR datasets but lack clear insights into employee performance, satisfaction, turnover, and training effectiveness.  
This dashboard was created to transform raw HR data into meaningful insights that support data-driven HR decisions.

## Business Requirements
- Analyze overall workforce distribution and demographics
- Evaluate employee performance across departments
- Understand compensation patterns and bonus distribution
- Track employee turnover and retention trends
- Measure engagement, satisfaction, and training completion

## Key Insights Covered
- Total employees, retention rate, and satisfaction score
- Department-wise salary and performance analysis
- High and low performers identification
- Employee turnover trends and reasons for leaving
- Training completion and engagement analysis
- Workforce distribution by gender, age, education, and location

## Tools Used
- Power BI
- Microsoft Excel (for data preparation)
